# CS比赛数据检索和分析 - 地图打法篇
## 一、核心地图全解析（现役Major/顶级赛事主流地图）
### 1. Inferno（炼狱小镇）
- **T方核心打法**：
  1.  A点快攻：香蕉道控权+烟雾弹封锁警家，配合闪光弹rush包点，适合前1分钟抢节奏
  2.  B点慢控：中路控权+连接烟雾封锁，逐步蚕食包点，适合打信息差
  3.  经典战术：香蕉道控权后转A，利用烟雾弹封锁CT回防路线
- **CT方核心打法**：
  1.  A点防守：大坑+包点双架，烟雾弹封锁香蕉道入口，配合闪光弹反清
  2.  B点防守：厨房+包点联动，烟雾弹封锁中路，防止T转点
  3.  回防战术：A点回防走警家，B点回防走连接，烟雾弹封锁包点视野
- **关键道具点位**：
  - T方：香蕉道过点烟、A包点警家烟、中路连接烟
  - CT方：香蕉道反清闪、A大坑烟雾弹、B厨房隔断烟

### 2. Mirage（荒漠迷城）
- **T方核心打法**：
  1.  A点快攻：A1烟雾封锁警家，配合闪光弹rush，适合职业战队快节奏战术
  2.  B点慢控：市场控权+烟雾封锁B小，逐步推进包点
  3.  转点战术：A点佯攻后转B，利用烟雾弹封锁CT回防
- **CT方核心打法**：
  1.  A点防守：A1+A2双架，烟雾弹封锁A1入口，配合闪光弹反清
  2.  B点防守：B小+包点联动，烟雾弹封锁市场，防止T控权
  3.  回防战术：A点回防走警家，B点回防走中路，烟雾弹封锁包点
- **关键道具点位**：
  - T方：A1警家烟、B小过点烟、中路拱门烟
  - CT方：A1反清闪、B小隔断烟、中路拱门闪

### 3. Nuke（核子危机）
- **T方核心打法**：
  1.  外场快攻：烟雾封锁外场CT视野，rush外场后控内场
  2.  内场慢控：烟雾封锁铁门，逐步推进包点
  3.  上下联动：外场控权后转内场，配合闪光弹夹击
- **CT方核心打法**：
  1.  外场防守：屋顶+铁门双架，烟雾弹封锁外场入口
  2.  内场防守：包点+黄房联动，烟雾弹封锁铁门
  3.  回防战术：外场回防走屋顶，内场回防走黄房
- **关键道具点位**：
  - T方：外场过点烟、铁门烟、内场包点烟
  - CT方：外场反清闪、铁门隔断烟、内场包点闪

### 4. Overpass（死亡游乐园）
- **T方核心打法**：
  1.  A点快攻：烟雾封锁A大，rush包点
  2.  B点慢控：厕所控权+烟雾封锁B大，逐步推进
  3.  转点战术：A点佯攻后转B，利用烟雾弹封锁CT回防
- **CT方核心打法**：
  1.  A点防守：A大+包点双架，烟雾弹封锁A大入口
  2.  B点防守：厕所+包点联动，烟雾弹封锁B大
  3.  回防战术：A点回防走警家，B点回防走厕所
- **关键道具点位**：
  - T方：A大警家烟、B大过点烟、厕所烟
  - CT方：A大反清闪、B大隔断烟、厕所闪

### 5. Vertigo（殒命大厦）
- **T方核心打法**：
  1.  A点快攻：烟雾封锁A大，rush包点
  2.  B点慢控：烟雾封锁B小，逐步推进
  3.  上下联动：A点控权后转B，配合闪光弹夹击
- **CT方核心打法**：
  1.  A点防守：A大+包点双架，烟雾弹封锁A大入口
  2.  B点防守：B小+包点联动，烟雾弹封锁B小
  3.  回防战术：A点回防走警家，B点回防走B小
- **关键道具点位**：
  - T方：A大警家烟、B小过点烟、中路烟
  - CT方：A大反清闪、B小隔断烟、中路闪

## 二、地图打法核心原则
1.  **控权优先**：无论T/CT，优先控制地图关键通道（香蕉道、A大、中路等），掌握比赛主动权
2.  **道具配合**：烟雾弹封锁视野、闪光弹突破/反清、燃烧弹封锁走位，是职业比赛核心
3.  **信息差**：通过侦查、假打获取CT/T位置，针对性调整战术
4.  **回防效率**：CT方回防必须配合道具，避免正面硬刚；T方必须做好回防拦截
5.  **经济管理**：根据经济情况调整战术，ECO局适合快攻/偷点，长枪局适合慢控

## 三、常见问题解答
### Q1：Inferno香蕉道怎么控权？
A：T方：2人香蕉道，1烟1闪，烟雾封锁CT视野，闪光弹反清，快速占领香蕉道；CT方：1人香蕉道，烟雾封锁入口，配合闪光弹拖延，等待队友支援。

### Q2：Mirage A点快攻怎么打？
A：T方：3人A1，1烟（警家）2闪，快速rush包点，1人断后；CT方：2人A点，烟雾封锁A1，闪光弹反清，等待中路队友回防。

### Q3：Nuke外场怎么防守？
A：CT方：2人外场，1烟（外场入口）1闪，屋顶+铁门双架，防止T rush，等待内场队友支援。

### Q4：Overpass B点怎么慢控？
A：T方：2人厕所，1烟（B大）1闪，逐步推进，1人断后，配合中路队友转点；CT方：2人B点，烟雾封锁B大，闪光弹反清，等待A点队友回防。

### Q5：Vertigo上下联动怎么打？
A：T方：2人A点，2人B点，烟雾封锁A大/B小，闪光弹夹击，1人断后；CT方：2人A点，2人B点，烟雾封锁A大/B小，闪光弹反清，等待队友回防。
